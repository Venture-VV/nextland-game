# 清晰度和矢量源文件

> 业主的要求(11 月 16 日):注意清晰度,最好原画级别;所有美术素材都要有一份矢量源文件,
> 最好分层、拆好元素。让去 GitHub 上找现成的方案。这份文档写的是找到了什么、用了什么、做到什么程度。

## 1. 结论

| 要求 | 现在的做法 | 做到的程度 |
|---|---|---|
| 清晰 | 每张母版用二次元专用的放大模型放大 4 倍,仓库里存 2 倍的高清版 | 线条、睫毛、发丝比直接拉大清楚得多;运行时的立绘从 720 宽提到 1080 宽 |
| 矢量源文件 | 每张母版自动拆层、描成路径,存成分层的 SVG | 每张都有;能在 Inkscape、Illustrator、Figma 里按层打开、改色、挪动 |
| 分层拆元素 | 背景、服装、皮肤、头发、暗部与线条、霓虹光,最多六层 | 靠颜色和位置判断,**边界不完全准**,见第 4 节 |

需要说清楚的一点:**这是从位图自动描出来的矢量,不是手绘的矢量稿。** 渐变被描成一圈圈色块,放得很大时能看出来。
它的用处是给美术一个能直接上手改的起点,和「每张图都有可编辑的源文件」这个流程要求对上;
要真正的原画级矢量,还是得有人在这个基础上重描关键部位(脸、手、轮廓)。

## 2. 文件在哪

```
art/biao/masters/   母版:出图工具给的原图,832×1216
art/biao/hires/     高清版:放大 4 倍后缩到 2 倍,1664×2432
art/biao/vector/    矢量源文件:每张一个分层 SVG;layers.json 记着每层的面积和路径数
assets/biao/        运行时用的图,从高清版裁出来
.work/art/up4x/     4 倍的原始结果(3328×4864,每张十来兆,不进仓库,重跑工具就有)
```

## 3. 怎么重做

```bash
python3 tools/upscale.py
```

```bash
python3 tools/vectorize.py
```

```bash
python3 tools/build_biao_assets.py
```

前两个第一次跑会从 Hugging Face 下载两个模型到 `.work/models/`(共约 250 MB)。都在 CPU 上跑,不需要显卡:
放大每张两三分钟,描矢量每张十几秒。需要的 Python 包:`onnxruntime`、`huggingface_hub`、`opencv-python-headless`、`vtracer`、`numpy`、`Pillow`。

## 4. 拆层是怎么判断的,哪里会不准

1. 先用抠图模型把人物从背景里分出来 → 「背景」层。
2. 人物里很亮、很艳的品红和冰青 → 「霓虹光」。
3. 偏橙红的浅色,而且和脸连着或者面积够大(手) → 「皮肤」。脸在哪取自 `art/biao/cast.json`。
4. 取额头上方一带的主色,头部范围里颜色相近的 → 「头发」。
5. 剩下的里面很暗的 → 「暗部与线条」;其余 → 「服装」。

已知会不准的地方:

- 脸被冷色的霓虹光罩住时(顾轩),肤色不在「偏橙红」的范围里,皮肤层分不出来,脸会留在「服装」层。
- 深色头发和深色衣领挨着时,衣领会被一起算进「头发」(林鸮)。
- 戴头盔、不露脸的(对手),没有皮肤和头发两层。
- 页面背景不拆人物,只分「远景与建筑」和「灯光」两层。

这些都可以在矢量软件里把路径拖到正确的层来修;要自动分得更准,得换成能「认得」部位的分割模型(见下一节的 SvgIt)。

## 5. 在 GitHub 上找到的,以及为什么这么选

| 项目 | 是什么 | 用没用 |
|---|---|---|
| `visioncortex/vtracer` | 把位图描成彩色矢量路径,速度快,有 Python 接口 | **用了**,每一层都是它描的 |
| `skytnt/anime-seg` | 二次元人物抠图模型 | **用了**,分背景和人物 |
| `deepghs/cdc_anime_onnx`(CDC) | 二次元 4 倍放大模型,ONNX 格式,CPU 能跑 | **用了**,放大母版 |
| `xinntao/Real-ESRGAN`(anime 6B) | 最常见的二次元放大模型 | 没用:官方只给 PyTorch 权重和需要显卡接口的可执行文件,这台机器上装不上对应的 Python 包。效果和 CDC 是一个量级 |
| `xuer98/svgit` | 先用分割模型(FastSAM)认出一个个物体,再每个物体一个图层地描成 SVG | 思路照着学了(先分块再描);没直接用:它要装 PyTorch 和分割模型,体积大,而且通用分割模型对二次元人物的头发、皮肤分得并不稳 |
| `Picsart-AI-Research/LIVE-Layerwise-Image-Vectorization` | 研究级的逐层矢量化,出来的路径最少、最像手绘 | 没用:一张图要优化几十分钟到几小时,需要显卡 |
| `AHEKOT/ComfyUI_VNCCS` | 视觉小说立绘的整套流程:建角色、换装、换表情、出透明底立绘 | 没用:要本地跑 ComfyUI 和显卡。有显卡的话,这是做「同一角色多表情」最省事的路 |
| `fromtheexchange/image2svg-awesome` | 位图转矢量的工具清单 | 查资料用 |

## 6. 还能怎么提高

- **有显卡的电脑**:用 ComfyUI 直接出 2 倍以上的原图(而不是先出小图再放大),清晰度是真细节而不是「猜」出来的;再配 VNCCS 做多表情。
- **手工**:在 `art/biao/vector/` 的基础上,让美术重描脸和手的轮廓、把渐变换成真正的矢量渐变。
- **分得更准**:接一个二次元部位分割模型,代替现在按颜色的判断。
