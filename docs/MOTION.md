# 动效:学到的算法和打算怎么用

> PR2 的实现依据。目的是把「为什么这样动」讲清楚,任何人照着都能实现,不依赖动画库。
> yuzu 库的动效套件只作参考,这里的内容来自对下面几处的学习,再按游戏的需要重新组织。

## 1. 学了哪些地方

| 来源 | 是什么 | 学到的 |
|---|---|---|
| React Bits(reactbits.dev) | 两百多个开源动效组件:文字、光标、卡片、背景 | 效果的分类;读了像素转场和滚动数字两个组件的算法 |
| Motion(motion.dev) | 最主流的网页动效库 | 弹簧的参数模型;布局过渡(先量位置再用变换补间);共享元素 |
| 一份公开的动效手艺笔记(memi-design) | 时长、曲线、依次出现的经验数值 | 各类交互的时长区间;依次出现的间隔公式 |
| 游戏手感方面的公开资料 | 打击感、奖励感怎么做 | 预备动作、顿帧、震屏、挤压拉伸、奖励弹出 |
| yuzu 的 `docs/UI_V8016.md` | 后台系统的动效规矩 | 退场影子的做法;「减少动态效果」的处理 |

没用上的:业主账号上连着的 AnimatedWebs 需要重新登录,这次读不了。重新登录后可以补看它的组件库。

学的是做法,不搬代码。React Bits 的许可带有附加条款,更不能直接拿。

## 2. 原则

1. **两类动效分开想。** 一类帮人看懂界面发生了什么(从哪来、到哪去、谁盖着谁);一类给游戏手感(打中了、拿到了、变强了)。前一类要克制,后一类可以夸张。
2. **只动变换、透明度、滤镜。** 不动宽高和位置属性,不引起重排。
3. **进出成对,退出更快。** 退出用进入的 50%~70% 时间。
4. **能被打断。** 用弹簧而不是固定时长的补间:动到一半目标变了,带着当前速度拐过去,不跳、不重来。
5. **只在第一次出现时播。** 列表刷新不重播。
6. **系统开了「减少动态效果」**:保留透明度和颜色变化,去掉位移、缩放、旋转、回弹、循环动画和震屏。
7. **同时在动的层不超过十几个。** `will-change` 只在动的时候加。
8. **不加动画库。**

## 3. 时长与曲线

| 类别 | 时长 | 例子 |
|---|---|---|
| 微交互 | 100~200ms | 按下 100、开关 150、图标替换 120 |
| 状态变化 | 200~400ms | 弹窗进 300 出 200、页签 250、提示 350、卡片展开 350 |
| 页面级 | 300~600ms | 淡入淡出 300、滑动切页 400、共享元素变形 500 |

| 名称 | 曲线 | 用在 |
|---|---|---|
| 利落 | `cubic-bezier(0.2, 0, 0, 1)` | 大多数进场 |
| 柔和 | `cubic-bezier(0.4, 0, 0.2, 1)` | 来回都要顺的移动 |
| 进场 | `cubic-bezier(0, 0, 0.2, 1)` | 从屏幕外进来 |
| 退场 | `cubic-bezier(0.4, 0, 1, 1)` | 离开 |
| 回弹 | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 小元素,400ms 以内 |
| 匀速 | `linear` | 只用于转圈和进度条 |

数值:按下缩到 0.97;成功时冲过头 5%~10%;进场位移 16~24px,退场 8~16px;从元素的视觉中心缩放,面板从它贴着的那条边滑出。

## 4. 算法

### 4.1 弹簧

阻尼弹簧:`加速度 = -k·(x - 目标) - c·速度`。直接调刚度和阻尼不直观,改用「周期」和「回弹」两个量:

```
ω = 2π / 周期        ζ = 1 - 回弹
k = ω²               c = 2·ζ·ω
```

每帧按约 240Hz 分小步积分(先更新速度再更新位置),这样帧率掉了也稳定。位置差小于 0.001 且速度小于 0.01 时算停下。

| 预设 | 周期 | 回弹 | 用在 |
|---|---|---|---|
| 利落 | 0.35s | 0.1 | 按钮、页签滑块 |
| 平顺 | 0.5s | 0 | 面板、地图回弹 |
| 弹 | 0.55s | 0.35 | 奖励弹出、勾选 |
| 沉 | 0.8s | 0.1 | 大卡片、立绘入场 |

停不下来超过 0.8 秒的弹簧就是太软了。纯 CSS 的地方,把弹簧按 20ms 采样成 `linear()` 曲线来用。

### 4.2 二阶跟随

让一个量「跟着」另一个量,并且可以调出预备动作和过冲。三个参数:频率 `f`、阻尼 `ζ`、初始响应 `r`。

```
k1 = ζ / (π·f)      k2 = 1 / (2π·f)²      k3 = r·ζ / (2π·f)
每帧:  y  += dt · yd
        yd += dt · (x + k3·xd - y - k1·yd) / max(k2, dt²/2 + dt·k1/2, dt·k1)
```

`r` 小于 0 时先往反方向缩一下再出发(预备动作),大于 1 时会冲过头。用在:镜头跟随、伤害数字跟着角色、立绘随手指轻微偏移。

### 4.3 与帧率无关的趋近

`a += (b - a) · (1 - e^(-λ·dt))`。不要写成 `a += (b - a) · 0.1`,那样帧率不同速度就不同。

### 4.4 依次出现

`每项延迟 = clamp(0.6 / 项数, 0.015, 0.08) 秒`,总共不超过 0.6 秒,只带前 12 项。两个变体:从中间往两边;从点击的位置往外扩散(延迟 = 距离 ÷ 速度)。

### 4.5 布局过渡与共享元素

四步:记下变化前的位置和大小 → 让变化发生 → 量出新的位置和大小 → 用变换把元素摆回旧样子,再用弹簧放开。大小变化用缩放实现,所以里面的内容要反向缩放才不会变形。

用在:装备从仓库格子飞到角色的装备槽;奖励图标飞进资源胶囊;页签下面的滑块;卡片展开成详情窗。

### 4.6 退场影子

关掉一个弹窗时,逻辑上马上移除(后面的页面立刻能点),同时复制一份不能点的副本播完退场再删。

### 4.7 像素块转场

原版战斗里,角色出场和被击破就是像素块,所以这是游戏自己的语言,值得用到页面切换和表里翻面上。

把画面分成每行 10~14 格的方格。每格有一个 0~1 的延迟值,决定它什么时候出现。分两段,各约 0.4 秒:先用色块盖住旧画面,盖满时换内容,再让色块消失露出新画面。

延迟值的四种取法:按格子坐标算出的伪随机数;4×4 的有序抖动矩阵;离某一点的距离(从点击处扩散);离某条边的距离(擦除)。后两种可以混进 30% 的随机,边缘不会太齐。

### 4.8 滚动数字

每一位是一条从 0 到 9 的竖带,只露出一个数字。设这一位当前的动画位置是 `pos`,数字 `n` 的纵向偏移是 `wrap(n - pos) × 100%`,`wrap` 把差值折到 -5 到 5 之间,这样 9 滚到 0 不会倒着绕一圈。`pos` 用弹簧(周期 0.7 秒,回弹 0.2)追目标值,各位之间错开 0.04 秒。滚得快时加一点纵向模糊。

用在:战力、资源胶囊、奖励数量。

### 4.9 震屏

维护一个 0~1 的「创伤值」。受到冲击时加上去,每秒线性衰减约 1.2。实际震动幅度取它的平方:`偏移 = 最大偏移 × 创伤² × 噪声(时间 × 频率)`。平方让小冲击几乎不晃、大冲击很猛,连续冲击会叠加但不会无限大。只移动镜头或舞台,不影响点击判定。

### 4.10 顿帧

重击命中的瞬间,把画面定住 2~5 帧(约 30~80 毫秒)。只停画面,不停规则和音乐。

### 4.11 挤压与拉伸

体积看起来不变:横向放大多少,纵向就缩小多少。按下 0.97;落地先压到 0.9,弹到 1.05,再回 1;高速移动时沿运动方向拉长,最多 25%。

### 4.12 预备动作

主动作之前,先朝反方向动 8%~12%,持续 80~120 毫秒。告诉人「接下来要发生什么」。

### 4.13 粒子

预先建好一批反复用。迸发时速度随机(0.35~1.25 倍),受重力,速度按指数衰减,寿命 0.35~0.85 秒,用叠加混合。奖励用的彩纸再加一个左右摆动和翻转。

### 4.14 倾斜与全息卡

指针在卡片上的相对位置是 `(px, py)`,都在 0~1 之间。`绕横轴转 = -(py - 0.5) × 最大角`,`绕纵轴转 = (px - 0.5) × 最大角`,最大角 10~14 度,用弹簧平滑。高光是一条渐变,位置跟着指针走;全息箔是一层彩虹渐变加「颜色减淡」混合。手机上可以改用陀螺仪。

用在:立绘卡、装备详情、抽卡结果。

### 4.15 磁吸、橡皮筋、惯性

- 磁吸:指针进入元素周围一定半径后,元素朝指针偏移 `(指针 - 中心) × 强度`,离开后用弹簧回去。
- 橡皮筋:拖过边界时越拖越费劲,`显示位移 = 上限 × (1 - 1 / (位移 × 0.55 / 上限 + 1))`。
- 惯性:松手后速度按 `e^(-t/τ)` 衰减,`τ` 约 0.325 秒;可以提前算出停在哪:`终点 = 当前 + 速度 × τ`。

用在:主页地图的拖动。现在松手就停、到边就卡住,要改成有惯性、到边回弹。

### 4.16 文字

- 逐字出现:拆成单字,依次从模糊到清晰。
- 解码:先显示乱码,从左到右逐个定成真正的字。
- 扫光:一道亮带从左扫到右。
- 打字机:剧情对白已有。

### 4.17 流光描边

一个亮点沿着元素的轮廓跑一圈。用在「可以领取」「已就绪」这类需要被注意到的按钮上,代替一直闪。

### 4.18 抽卡的编排

1. 预备:补给箱震动 0.4 秒,越来越剧烈。
2. 开启:白光一闪,顿帧 60 毫秒。
3. 发牌:卡片一张张飞到位,间隔 50 毫秒,用弹簧。
4. 翻面:绕纵轴转 180 度,转到一半时放大到 1.08。
5. 品质:白、绿没有额外效果;蓝有柔光;紫有一道光柱;橙有放射光并且全屏染色。
6. 任何时候点一下都可以直接看结果。

## 5. 两档

量过每秒 15 帧的录屏:原版的弹窗和页面都是直接出现的,没有过渡;浮动提示和「战力提升」从左边滑进来;奖励图标约 0.2 秒淡入;「战力提升」的数字是滚着涨上去的。所以「原版」档就这些。

| 效果 | 原版档(`orig`) | 升级档(`plus`,默认) |
|---|---|---|
| 弹窗、对话框 | 直接出现,直接消失 | 带回弹地弹入;关掉时留影子淡出 |
| 页面切换 | 直接切 | 轻微上浮;底部页签之间按左右方向滑 |
| 浮动提示、战力提升 | 从左滑入 | 从左滑入,带回弹;数字每一位各自滚动;扫光 |
| 领奖 | 图标淡入 | 图标依次弹出;关掉后飞向资源栏或底部导航;资源栏的数字滚到新值 |
| 按下反馈、流光描边、点触光圈 | 无 | 有 |
| 主页地图 | 松手就停,到边卡住 | 惯性,到边回弹 |
| 登录进主页、进战斗 | 直接切 | 像素块转场 |
| 十连补给 | 卡片直接出现 | 白光、发牌翻面、蓝紫橙三档光效、点一下直接看结果 |
| 穿戴装备 | 无 | 图标飞到装备格 |
| 立绘倾斜、高光、呼吸 | 无 | 部件已写好,等表的立绘 |

开关在「设置」里;地址后加 `?motion=orig` 也可以。系统开了「减少动态效果」时,两档都只留透明度变化。

战斗里的震屏、火花、像素块属于战斗本身,不随这个开关变;只在「减少动态效果」时关掉震屏。

## 6. 怎么验收

- 走查脚本里有一组动效检查:影子 0.5 秒内清掉;奖励图标飞出、数字滚到位;像素块转场中途换内容、结束后清掉;原版档弹窗直接出现;「减少动态效果」时只有淡入、没有位移(用 `NL.testReduced = true` 模拟)。
- 逐页对照(`tools/compare.cjs`)一律用原版档,免得截图停在动画半路。
- 流畅度要在真机上看,无头浏览器测不出来。**这一条还没人做过。**
