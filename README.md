# nextland-game

《新生乐园世界》小游戏的网页复刻演示。目的是验证「只凭一段录屏,让 AI 把游戏复刻成能在浏览器里跑的版本」是否可行。

唯一的输入是 `videos/` 里那段 7 分 43 秒的手机录屏。没有原工程、配置表和原始素材。

在线地址:https://venture-vv.github.io/nextland-game/ (由 `main` 分支自动发布)。合并到 `main` 后约 1 分钟生效,刷新一次页面即可看到新版。

## 怎么跑

不需要安装和构建。任选一种:

- 直接双击 `index.html`,用浏览器打开。
- 或者在仓库根目录起一个静态服务器,再打开 `http://localhost:8000`:

```bash
python3 -m http.server 8000
```

画面按手机竖屏(360×781)设计,在电脑上会按窗口高度等比缩放并居中,手机上直接铺满。进度存在浏览器本地。

- 地址后加 `?reset` 清空存档重来。
- 地址后加 `#home`、`#role`、`#shop` 这样的页面名,跳过登录直接进某个页面。

## 做了什么

先用 5 次提交把录屏里出现过的页面都复刻出来,之后按反馈加了背景音乐并重做了战斗。

| 阶段 | 内容 |
|---|---|
| 复刻 1 | 骨架与素材:从录屏截取素材、拼出园区地图;竖屏舞台、底部导航、存档;防沉迷公告、登录、主页 |
| 复刻 2 | 任务(日常 / 主线 / 支线 / 探索)、剧情对话、领奖弹窗、互动码、线下引导 |
| 复刻 3 | 角色(档案、装备、接口升级、芯片、权益加成)、仓库(道具、装备、分解)、伙伴(协议、赠礼、档案、等级权益、每日委托) |
| 复刻 4 | 冒险地图与关卡、战斗、玩法列表与探索列车、排行榜(排位战、挂机奖励)、商城、补给(单抽、十连) |
| 复刻 5 | 邮件、好友、个人、票券、绑定管理、设置、活动日历、互动、园区平面图、种族与势力;自动走查脚本;差异清单 |
| 之后 | 背景音乐与声音开关;3D 的节拍对决 |
| 保真度 | 逐页和录屏对照并修正;弹窗按录屏重排;照录屏复刻原版战斗;商城购买窗 |
| 动效 | 动效套件,分「升级」和「原版」两档 |
| 表里 | 一键翻面的骨架;表的界面配色层 |
| 表的角色 | 画风手册;六位伙伴和主角的立绘;伙伴页换装 |

共 28 个页面和十几种弹窗。能玩的主线是:领任务奖励升级 → 穿装备、升接口提高战力 → 打关卡和探索列车拿装备箱和晶片 → 补给抽装备 → 给伙伴送礼、做委托。

## 声音

- **背景音乐**取自录屏的音轨。它是一首 168 秒的循环曲,截出正好一个循环,首尾相接播放。
- **战斗音乐**也取自录屏:进战斗时背景音乐暂停,换成战斗曲;打完后背景音乐从暂停的地方接着放,和原版一样。录屏里的战斗最长只有 8.7 秒,所以战斗曲是把其中 8 拍首尾相接循环。
- **战斗音效**(击中、格挡、爆发、击破、胜负)是用浏览器合成的。录屏里的战斗只有音乐,没有音效。
- **开关**:右上角的小喇叭随时可以点,任何页面包括战斗中都在;「设置」里也有同一个开关。选择会记住。
- 浏览器规定要等第一次点击之后才能出声,所以音乐是从点掉公告那一下开始的。

## 战斗

默认是 **3D 节拍对决**,这是在原版基础上重新设计的:

- **3D 场景**:霓虹擂台上两个悬浮的「战斗核心」(头像取自录屏),带镜头摇动、冲刺残影、击中火花和震屏。
- **跟着节拍打**:战斗曲每拍 0.923 秒,双方轮流出手,每一击都落在重拍上。
- **格挡**:对手出手时,我方头像外有一圈光环向内合拢,合拢的瞬间点「格挡」(或点场地任意位置),这一击只吃 80% 伤害。每一击只能试一次,点早了算失误。
- **爆发**:出手和挨打都会攒能量,攒满后点「爆发」,下一击变成光束,伤害 140%。
- **胜负**:什么都不点时和原版一样,战力不低于对手就赢。只用爆发,战力达到对手的 86% 就能赢;爆发加每次都格挡,76% 就能赢。
- 浏览器不支持 WebGL 时自动退回 2D 画法,规则相同。

3D 用的是 three.js(MIT 许可),放在 `vendor/` 里,不依赖外网。

在「设置」里关掉「3D 节拍对决」,就换回**原版战斗**。它是照录屏 4:29–4:37 那一场复刻的:「战斗开始」横幅 → 霓虹网格隧道里双方头像带着青色像素块翻进来 → 自动对撞三次,每次有白黄色闪光和火花 → 输的一方飘到正中,发光、缩小,碎成绿色像素块 → 「挑战成功」和奖励。玩家只能看,可以点「跳过战斗」。原版战斗只有音乐没有音效,这里也一样。

## 表 / 里

主页左侧有一个「表 / 里」翻面按钮(「设置」里也有一行,地址后加 `?skin=biao` 也行):

- **里**:照录屏复刻的原样,默认是这一面。
- **表**:重画的女性向美术,方向是二次元精致立绘加赛博霓虹。**现在换好的有**:界面的配色层(按钮、弹窗、对话框、提示、页签、卡片),以及登录页、主页、伙伴列表、伙伴页、角色页(六位伙伴和主角的新立绘)和战斗里双方的头像。表的主页没有可拖动的地图:原来点地图上建筑的入口,排成了一排地点按钮。其余页面的立绘和整页底图还没有画,暂时借用里的。画风手册在 `docs/ART_BIBLE_BIAO.md`,每张图的来历在 `docs/ART_PROVENANCE.md`。这些图是 AI 生成的。

两面共用同一份规则和存档,翻面只换画面。表的图放在 `assets/biao/`,和里的图同名同路径,放进去后跑一次 `python3 tools/skin_assets.py` 就会自动换上。

## 动效

分两档,在「设置」里用「升级动效」开关切换(地址后加 `?motion=orig` 也行):

- **升级动效(默认)**:弹窗带回弹地弹入、关掉时留影子淡出;领奖时图标依次弹出,关掉后飞向资源栏,数字滚到新值;「战力提升」的数字每一位各自滚动;主页地图有惯性、到边回弹;登录进主页和进战斗用像素块转场;十连补给有发牌、翻面和按品质分档的光效;穿戴时装备图标飞到装备格;按钮有按下反馈,可领取的按钮有流光描边。
- **原版动效**:照录屏。原版的弹窗和页面是直接出现的,只有浮动提示滑入、奖励淡入、战力数字滚动。

系统开了「减少动态效果」时,两档都只留透明度变化。做法和参数写在 `docs/MOTION.md`,代码在 `js/motion.js` 和 `css/motion.css`,没有用动画库。

## 和录屏逐页对照

`docs/fidelity/README.md` 是一张总表:65 个画面,每个都把网页版摆到录屏当时的状态,和那一帧并排,给出相似度和「明显不同的面积」,附三联图(录屏、网页版、差异)。重新生成:

```bash
node tools/compare.cjs
```

```bash
python3 tools/compare.py
```

分数是把两张图缩到同一尺寸、稍微模糊后逐点比出来的。它对位置和颜色敏感,对字体不敏感,所以只能当「哪里还差得多」的线索,不能当「一模一样」的证明。

## 怎么验证

`tools/walkthrough.cjs` 会在无头浏览器里把 11 组流程各走一遍,任何脚本报错、点不到的按钮或不符合预期的结果都会让它失败,并把画面截图存到 `.work/shots/`。截图是 720×1562,和录屏同尺寸,可以直接并排比。

```bash
node tools/walkthrough.cjs
```

需要先装好 playwright。脚本先检查版本号是否最新(见下面「发布前」),再走 11 组流程:登录与主页(含背景音乐的开、关、再开)、任务与剧情、角色仓库伙伴、冒险与各种玩法(含购买窗)、外围界面(含设置里的两个开关)、原版战斗(定在固定时刻截图,检查胜、负、跳过,以及卸下和重新穿戴装备)、动效(退场影子、奖励飞入与数字滚动、像素块转场、两档切换、减少动态效果)、3D 节拍对决(格挡、爆发、击破、结算和音乐切换)、没有 WebGL 时退回 2D。另有一组表里翻面;最后把同一组步骤在两种皮肤下各跑一遍,检查存档逐项相同。

没有验证到的:声音只确认了「在播放」和「开关、切换的时机」,**没有人实际听过**;动效只检查了「有没有、清没清掉」,**流畅度没有在真机上看过**;没有在真机(iOS、安卓、微信内置浏览器)上试过。

## 发布前

改了脚本、样式或音乐之后,提交前跑一次:

```bash
python3 tools/stamp.py
```

它给 `index.html` 里引用的每个文件加上按内容算出的版本号,并更新 `version.txt`。GitHub Pages 让浏览器把每个文件缓存 10 分钟,不加版本号的话,发布后普通刷新只会更新页面本身,脚本和样式还是旧的,新旧混在一起看起来就像没更新。页面打开后还会拿自己的版本号和 `version.txt` 比一下,发现自己是旧页面就自动重新加载一次。

## 素材是怎么来的

图片和音乐全部来自录屏,没有重画、重录。

- `tools/extract_assets.py`:把录屏按每秒 2 帧抽成整帧,再按 `tools/asset_manifest.py` 里的清单(第几帧、哪个矩形)裁出素材。清单里还记着每张图要做的小修补,例如抹掉图标上烙着的数量、从另一帧取一块盖住转场中的文字。
- `tools/build_map.py`:录屏里有一段在主页连续拖动地图。脚本把这段逐帧对齐,拼成一整张可拖动的园区地图;再利用「HUD 不动、地图在动」把主页 HUD 从地图上分离出来,得到带透明度的按钮和名片。
- `tools/build_audio.py`:从音轨里取出背景音乐的一个完整循环和战斗音乐。循环长度(168.365 秒)和节拍(65 拍/分)是把音轨和它自己对齐量出来的,脚本开头写着音轨的结构。
- `tools/build_embeds.py`:把 3D 战斗要用的两张头像和战斗音乐写进 `js/embed.js`。双击打开时浏览器不允许把本地图片当 3D 贴图,所以要内嵌。
- 布局固定的页面(角色、伙伴详情、排行榜、补给等)直接用录屏整帧做底图,会变的数字由页面盖在上面。

重新生成(需要 ffmpeg、Python 3、Pillow、numpy),按这个顺序:

```bash
python3 tools/build_map.py
```

```bash
python3 tools/extract_assets.py
```

```bash
python3 tools/build_audio.py
```

```bash
python3 tools/build_embeds.py
```

## 与录屏不一致的地方

结论先说:**看起来和点起来与录屏接近,但做不到「完全一致」。** 逐页对照的平均相似度约 97%(见 `docs/fidelity/`)。录屏里只有画面和声音,规则、数值表和原始素材都不在里面,下面这些是只凭录屏补不回来、或者还没做的。

画面

- 字体用的是系统自带的中文黑体,和原游戏的字体不同。
- 主页地图只有录屏里拖到过的区域是真实画面。四周没拍到的地方按地砖纹理补齐,园区下沿有几栋建筑因此被截断。
- 整幅底图上烙着录屏当时的状态,不会跟着变:好友和角色上的红点、角色档案的四项属性、补给的保底计数(0/20、0/80 等)、玩法卡片上的「30/30」、排行榜上的头像和名次。
- 录屏开头有一小条状态栏黑边,个人页的底图里带着它。
- 列表行、弹窗、按钮等凡是内容会变的部分是用样式画的,不是原图,细节(描边、纹理、斜角)比原版简单。
- 右上角多了一个原版没有的声音开关;「设置」窗口下面多了「背景音乐」「3D 节拍对决」「升级动效」「表 / 里」四行;主页左侧多了一个翻面按钮。中间两个都关掉、停在「里」这一面,才是原版的样子。
- 弹窗里的小图标(装备详情左上的「对比」、绑定标记等)没有做。
- 补给结果页的装备图带着深色底,原版是抠掉底色的大图。

声音

- 战斗音乐只有录屏里拍到的 8.7 秒,循环起来比原曲单调。
- 战斗音效是合成的,原版(至少在这段录屏里)没有音效。
- 背景音乐是从录屏里转录的,经过了两次有损压缩,音质不如原文件。

战斗

- 原版战斗是照录屏里一场的画面和时间点做的:网格隧道是程序画的,不是原图;像素块和火花的数量、飞散方向是随机的,和录屏不会逐帧相同;对撞固定三次(录屏里那两场都是三次,别的场次是否不同不知道)。
- 所有对手用的都是同一张头像(录屏里的两场战斗也是同一张)。
- 其他关卡的对手名字和战力是按录屏里那两场外推的。

内容

- 剧情对白只有录屏里拍到的句子。玩家点得很快,没拍全的句子保留拍到的部分;录屏里没点开的剧情用一句说明代替。
- 装备的名字只有往事圆顶帽、勇士上衣、高地守卫上衣是录屏里读到的,其余是按同样风格补的。面板战力在录屏里读得到的 9 件照录屏(535、485、538、52、461、55、468、17、25),其余是补的。仓库原有 69 件装备,这里只放了录屏里看得清图标的 31 件。补给结果页里出现过的另外 9 个真名(勇士网格指环、W红色指环等)还没有对上图标,没有用上。
- 伙伴里顾轩没有被点开过,麻光耀的立绘在录屏里没加载出来,这两位在「里」没有立绘。除冀光外,其他伙伴档案里的年龄、生日、喜好、讨厌取自策划文档(星座是按生日推算的)。礼物有两种的名字出现在录屏里,另外四种的名字取自策划文档,说明文字是补的。
- 排行榜上 4~12 名的战力、好友推荐列表里录屏之外的名字、排行榜周结算邮件的奖励是补的。
- 「超弦武装」「灰环行动」「捕捉奇迹」三个玩法在录屏里点开时提示「页面打开失败。」,网页版照样只给这句提示。种族天赋、势力天赋、芯片背包、阪神金库、预约管理在录屏里没有点开,只给提示。

规则与数值

- 装备穿上后总战力涨多少,录屏里看不出规律(弹出的数字在滚动,面板 535 的帽子涨 535,有的却涨几千)。现在只保证开局 2.4 万、穿满 4.2 万和录屏一致,中间每一步是补的。
- 通关率的四档叫法(碾压、高、中、低)和分界取自策划文档,录屏里只出现过「碾压」。
- 数值只能照录屏里出现过的数字反推。对得上的有:16 级领 100 经验升到 21 级且战力 +889;全部穿戴后战力 4.2 万;接口升级花费 60、120、240;体力每 20 分钟恢复 1 点;关卡每次 6 点体力;挂机 1319 小时领 75140 晶片;委托刷新花费 10、15。没出现过的数字是补的。
- 补给的掉落池和概率、宝箱开出什么,录屏里看不到,是补的。
- 商城购买窗里的「宝箱内容」是补的。

联网与线下
