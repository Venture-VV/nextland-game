# nextland-game

《新生乐园世界》小游戏的网页复刻演示。目的是验证「只凭一段录屏,让 AI 把游戏复刻成能在浏览器里跑的版本」是否可行。

唯一的输入是 `videos/` 里那段 7 分 43 秒的手机录屏。没有原工程、配置表和原始素材。

在线地址:https://venture-vv.github.io/nextland-game/ (由 `main` 分支自动发布)

## 怎么跑

不需要安装和构建。任选一种:

- 直接双击 `index.html`,用浏览器打开。
- 或者在仓库根目录起一个静态服务器,再打开 `http://localhost:8000`:

```bash
python3 -m http.server 8000
```

画面按手机竖屏(360×781)设计,在电脑上会按窗口高度等比缩放并居中,手机上直接铺满。进度存在浏览器本地。

- 地址后加 `?reset` 清空存档重来。
- 地址后加 `#home`、`#role`、`#shop` 这样的页面名,跳过登录直接进某个页面。

## 做了什么

先用 5 次提交把录屏里出现过的页面都复刻出来,之后按反馈加了背景音乐并重做了战斗。

| 阶段 | 内容 |
|---|---|
| 复刻 1 | 骨架与素材:从录屏截取素材、拼出园区地图;竖屏舞台、底部导航、存档;防沉迷公告、登录、主页 |
| 复刻 2 | 任务(日常 / 主线 / 支线 / 探索)、剧情对话、领奖弹窗、互动码、线下引导 |
| 复刻 3 | 角色(档案、装备、接口升级、芯片、权益加成)、仓库(道具、装备、分解)、伙伴(协议、赠礼、档案、等级权益、每日委托) |
| 复刻 4 | 冒险地图与关卡、战斗、玩法列表与探索列车、排行榜(排位战、挂机奖励)、商城、补给(单抽、十连) |
| 复刻 5 | 邮件、好友、个人、票券、绑定管理、设置、活动日历、互动、园区平面图、种族与势力;自动走查脚本;差异清单 |
| 之后 | 背景音乐与声音开关;战斗重做成 3D 的节拍对决 |

共 28 个页面和十几种弹窗。能玩的主线是:领任务奖励升级 → 穿装备、升接口提高战力 → 打关卡和探索列车拿装备箱和晶片 → 补给抽装备 → 给伙伴送礼、做委托。

## 声音

- **背景音乐**取自录屏的音轨。它是一首 168 秒的循环曲,截出正好一个循环,首尾相接播放。
- **战斗音乐**也取自录屏:进战斗时背景音乐暂停,换成战斗曲;打完后背景音乐从暂停的地方接着放,和原版一样。录屏里的战斗最长只有 8.7 秒,所以战斗曲是把其中 8 拍首尾相接循环。
- **战斗音效**(击中、格挡、爆发、击破、胜负)是用浏览器合成的。录屏里的战斗只有音乐,没有音效。
- **开关**:右上角的小喇叭随时可以点,任何页面包括战斗中都在;「设置」里也有同一个开关。选择会记住。
- 浏览器规定要等第一次点击之后才能出声,所以音乐是从点掉公告那一下开始的。

## 战斗

原版的战斗是两个头像自动对撞,玩家只能看。这里按反馈**重新设计**了,不再是复刻:

- **3D 场景**:霓虹擂台上两个悬浮的「战斗核心」(头像取自录屏),带镜头摇动、冲刺残影、击中火花和震屏。
- **跟着节拍打**:战斗曲每拍 0.923 秒,双方轮流出手,每一击都落在重拍上。
- **格挡**:对手出手时,我方头像外有一圈光环向内合拢,合拢的瞬间点「格挡」(或点场地任意位置),这一击只吃 80% 伤害。每一击只能试一次,点早了算失误。
- **爆发**:出手和挨打都会攒能量,攒满后点「爆发」,下一击变成光束,伤害 140%。
- **胜负**:什么都不点时和以前一样,战力不低于对手就赢。只用爆发,战力达到对手的 86% 就能赢;爆发加每次都格挡,76% 就能赢。也就是操作得好,最多能越过比自己高三成左右的对手。
- 「跳过战斗」按不操作的结果直接结算。
- 浏览器不支持 WebGL 时自动退回 2D 画法,规则相同。

3D 用的是 three.js(MIT 许可),放在 `vendor/` 里,不依赖外网。

## 怎么验证

`tools/walkthrough.cjs` 会在无头浏览器里把 7 组流程各走一遍,任何脚本报错、点不到的按钮或不符合预期的结果都会让它失败,并把画面截图存到 `.work/shots/`。截图是 720×1562,和录屏同尺寸,可以直接并排比。

```bash
node tools/walkthrough.cjs
```

需要先装好 playwright。7 组流程是:登录与主页(含背景音乐的开、关、再开)、任务与剧情、角色仓库伙伴、冒险与各种玩法、外围界面、3D 战斗(定在固定时刻检查格挡、爆发、击破、结算和音乐切换)、没有 WebGL 时退回 2D。

没有验证到的:声音只确认了「在播放」和「开关、切换的时机」,**没有人实际听过**;没有在真机(iOS、安卓、微信内置浏览器)上试过。

## 目录

```
index.html          入口
css/                样式(app.css 通用组件,screens.css 各页面)
js/core.js          DOM 工具、存档、页面切换、通用弹窗、基础数值
js/data.js          数据表(物品、任务、剧情、装备、伙伴、关卡、商城……)
js/audio.js         背景音乐、战斗音乐、合成音效、声音开关
js/battle3d.js      3D 战斗的画面
js/embed.js         生成的文件:3D 战斗用的头像贴图和战斗音乐(base64)
js/screens/         各页面(battle.js 里是战斗的规则和时间轴)
assets/img/         从录屏截出来的图片素材(约 6 MB)
assets/audio/       从录屏截出来的背景音乐(约 2 MB)
vendor/             第三方代码(three.js)
tools/              素材工具和走查脚本(只在重新生成素材或验证时用,跑游戏不需要)
videos/             原始录屏(Git LFS)
```

## 素材是怎么来的

图片和音乐全部来自录屏,没有重画、重录。

- `tools/extract_assets.py`:把录屏按每秒 2 帧抽成整帧,再按 `tools/asset_manifest.py` 里的清单(第几帧、哪个矩形)裁出素材。清单里还记着每张图要做的小修补,例如抹掉图标上烙着的数量、从另一帧取一块盖住转场中的文字。
- `tools/build_map.py`:录屏里有一段在主页连续拖动地图。脚本把这段逐帧对齐,拼成一整张可拖动的园区地图;再利用「HUD 不动、地图在动」把主页 HUD 从地图上分离出来,得到带透明度的按钮和名片。
- `tools/build_audio.py`:从音轨里取出背景音乐的一个完整循环和战斗音乐。循环长度(168.365 秒)和节拍(65 拍/分)是把音轨和它自己对齐量出来的,脚本开头写着音轨的结构。
- `tools/build_embeds.py`:把 3D 战斗要用的两张头像和战斗音乐写进 `js/embed.js`。双击打开时浏览器不允许把本地图片当 3D 贴图,所以要内嵌。
- 布局固定的页面(角色、伙伴详情、排行榜、补给等)直接用录屏整帧做底图,会变的数字由页面盖在上面。

重新生成(需要 ffmpeg、Python 3、Pillow、numpy),按这个顺序:

```bash
python3 tools/build_map.py
```

```bash
python3 tools/extract_assets.py
```

```bash
python3 tools/build_audio.py
```

```bash
python3 tools/build_embeds.py
```

## 与录屏不一致的地方

结论先说:**除战斗外,看起来和点起来与录屏接近,但做不到「完全一致」;战斗是有意重新设计的,和录屏不同。** 录屏里只有画面和声音,规则、数值表和原始素材都不在里面,下面这些是只凭录屏补不回来的。

画面

- 字体用的是系统自带的中文黑体,和原游戏的字体不同。
- 主页地图只有录屏里拖到过的区域是真实画面。四周没拍到的地方按地砖纹理补齐,园区下沿有几栋建筑因此被截断。
- 整幅底图上烙着录屏当时的状态,不会跟着变:粉色的引导箭头、好友和角色上的红点、角色档案的四项属性、补给的保底计数(0/20、0/80 等)、玩法卡片上的「30/30」、排行榜上的头像和名次。
- 录屏开头有一小条状态栏黑边,个人页的底图里带着它。
- 列表行、弹窗、按钮等凡是内容会变的部分是用样式画的,不是原图,细节(描边、纹理、斜角)比原版简单。
- 右上角多了一个原版没有的声音开关。

声音

- 战斗音乐只有录屏里拍到的 8.7 秒,循环起来比原曲单调。
- 战斗音效是合成的,原版(至少在这段录屏里)没有音效。
- 背景音乐是从录屏里转录的,经过了两次有损压缩,音质不如原文件。

战斗

- 整个战斗是重新设计的(见上面「战斗」一节),画面、节奏、操作都和原版不同。原版是两个头像自动对撞,进场、对撞三次、落败一方碎成像素块,没有操作。
- 所有对手用的都是同一张头像(录屏里的两场战斗也是同一张)。
- 其他关卡的对手名字和战力是按录屏里那两场外推的。

内容

- 剧情对白只有录屏里拍到的句子。玩家点得很快,没拍全的句子保留拍到的部分;录屏里没点开的剧情用一句说明代替。
- 装备里只有金链、白手套、粉色护手、高地守卫上衣 4 件的名字和数值出现在录屏里,其余装备的名字和战力是按同样风格补的。仓库原有 69 件装备,这里只放了录屏里看得清图标的 31 件。
- 伙伴里顾轩没有被点开过,麻光耀的立绘在录屏里没加载出来,这两位没有立绘;除冀光外,其他伙伴的档案只有录屏里出现过的字段,其余显示「???」。礼物只有两种的名字出现在录屏里,其余是补的。
- 排行榜上 4~12 名的战力、好友推荐列表里录屏之外的名字、排行榜周结算邮件的奖励是补的。
- 「超弦武装」「灰环行动」「捕捉奇迹」三个玩法在录屏里点开时提示「页面打开失败。」,网页版照样只给这句提示。种族天赋、势力天赋、芯片背包、阪神金库、预约管理在录屏里没有点开,只给提示。

规则与数值

- 数值只能照录屏里出现过的数字反推。对得上的有:16 级领 100 经验升到 21 级且战力 +889;全部穿戴后战力 4.2 万;接口升级花费 60、120、240;体力每 20 分钟恢复 1 点;关卡每次 6 点体力;挂机 1319 小时领 75140 晶片;委托刷新花费 10、15。没出现过的数字是补的。
- 补给的掉落池和概率、宝箱开出什么,录屏里看不到,是补的。
- 商城购买在原版里是一个带数量滑条的购买窗,网页版简化成确认框,一次买一份。

联网与线下

- 这是纯前端演示,没有服务器。好友、排行榜上的其他玩家是固定数据,进度只存在本机浏览器里。
- 「出示互动码」原本要到园区找 NPC 扫码。网页版的码是假的(原码是账号的真实互动码,素材里已涂掉),另加了一个「模拟NPC扫码」按钮来完成任务。
- 玩家编号换成了占位值 `NLWEB0001`。绑定会员只在本页校验手机号格式,不发短信、不保存也不上传;扫码、兑换码、绑定装备、票券核销都只给提示。
