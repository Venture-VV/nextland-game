# nextland-game

《新生乐园世界》小游戏的网页复刻演示。目的是验证「只凭一段录屏,让 AI 把游戏复刻成能在浏览器里跑的版本」是否可行。

唯一的输入是 `videos/` 里那段 7 分 43 秒的手机录屏。没有原工程、配置表和原始素材。

## 怎么跑

不需要安装和构建。任选一种:

- 直接双击 `index.html`,用浏览器打开。
- 或者在仓库根目录起一个静态服务器,再打开 `http://localhost:8000`:

```bash
python3 -m http.server 8000
```

画面按手机竖屏(360×781)设计,在电脑上会按窗口高度等比缩放并居中。进度存在浏览器本地;地址后加 `?reset` 可以清空存档重来,加 `#home` 这样的页面名可以跳过登录直接进某个页面。

## 目录

```
index.html          入口
css/                样式(app.css 通用组件,screens.css 各页面)
js/core.js          DOM 工具、存档、页面切换、通用弹窗、基础数值
js/data.js          数据表
js/screens/         各页面
assets/img/         从录屏截出来的素材
tools/              素材工具(只在重新生成素材时用,跑游戏不需要)
videos/             原始录屏(Git LFS)
```

## 素材是怎么来的

全部来自录屏,没有重画。

- `tools/extract_assets.py`:把录屏按每秒 2 帧抽成整帧,再按 `tools/asset_manifest.py` 里的清单(第几帧、哪个矩形)裁出素材。
- `tools/build_map.py`:录屏里有一段在主页连续拖动地图。脚本把这段逐帧对齐,拼成一整张可拖动的园区地图;再利用「HUD 不动、地图在动」把主页 HUD 从地图上分离出来,得到带透明度的按钮和名片。

重新生成(需要 ffmpeg、Python 3、Pillow、numpy):

```bash
python3 tools/build_map.py
```

```bash
python3 tools/extract_assets.py
```

## 已知与录屏不一致的地方

随提交补充,最终清单在第 5 次提交。

- 地图只有录屏里拖到过的区域是真实画面。四周没拍到的地方按地砖纹理补齐,园区下沿有几栋建筑因此被截断。
- 字体用的是系统自带的中文黑体,和原游戏的字体不同。
- 剧情对白只有录屏里拍到的句子。玩家点得很快,没拍全的句子保留拍到的部分;录屏里没点开的剧情用一句说明代替。
- 「出示互动码」原本要到园区找 NPC 扫码。网页版的码是假的(原码是账号的真实互动码,素材里已涂掉),另加了一个「模拟NPC扫码」按钮来完成任务。
- 装备里只有金链、白手套、粉色护手、高地守卫上衣 4 件的名字和数值出现在录屏里,其余装备的名字和战力是按同样风格补的。仓库原有 69 件装备,这里只放了录屏里看得清图标的 31 件。
- 角色档案页的四项属性(力量、魅力、活力、结实)是底图上的固定数字,不随装备变化。种族天赋、势力天赋、芯片背包在录屏里没有点开,只给提示。
- 伙伴里顾轩没有被点开过,麻光耀的立绘在录屏里没加载出来,这两位没有立绘;除冀光外,其他伙伴的档案只有录屏里出现过的字段,其余显示「???」。礼物只有两种的名字出现在录屏里,其余是补的。
- 数值只能照录屏里出现过的数字反推(例如 16 级领 100 经验升到 21 级、体力每 20 分钟恢复 1 点),没出现过的按同样风格补。
